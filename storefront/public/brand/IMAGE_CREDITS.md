## Why this file exists

`hero-wine.jpg` is a **placeholder standing in for real LiquorCentral
photography**, not a final brand asset. It was chosen because it is the closest
available approximation of the direction in `BRAND_IDENTITY.md` §15–16 — a
studio-lit arrangement on a seamless light ground, with an *unbranded* bottle
(so the homepage does not appear to endorse, or infringe the trademark of, a
third-party producer LiquorCentral does not represent).

**It should be replaced** once real photography exists (`BRAND_GUIDELINES.md`'s
own open item). When it is, delete the row above along with the file — the hero
component reads the path from one constant and needs no layout change.
